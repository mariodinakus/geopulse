# GEOPULSE
Global intelligence explorer with interactive 3D globe, sourced headlines and five analysis modules.

Run: `npm install && npm run dev`

Render: Node runtime, build `npm install && npm run build`, start `npm start`.

Data integrity: markers are country reference positions, not live conflicts. GDELT is a best-effort feed. Historical, causal and scenario modules are exploratory interfaces, not verified predictive models. No API keys required.
